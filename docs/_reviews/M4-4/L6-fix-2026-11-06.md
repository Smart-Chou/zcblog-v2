# M4-4 · L6 修复（`verify-changeset-loop` 三包 tarball）

- 日期：2026-11-06
- 指令：PO「先做 2、3」——第 2 项修 L6；未 publish、未改 production。
- 结论：**L1–L8 8/8 PASS**；`changeset pack` 产出三包 tarball。

## 1. 原症状

`node scripts/release/verify-changeset-loop.mjs` 的 L6 红：

```text
[FAIL] L6  changeset pack 没产出三包 tarball
ELIFECYCLE ... prepack: node scripts/build.mjs
```

根因：M4-6 给 `packages/ui` 和 `packages/og-image` 加了 `prepack`，而临时 monorepo 只拷
metadata/包内容、不拷 `node_modules`，`prepack` 找不到 workspace 根的 `typescript`。

## 2. 失败的修法（记录，避免再踩）

曾尝试把真仓根 `node_modules` 软链到临时目录。结果 `pnpm exec prettier` 把软链解析回真仓，
直接 purge 了**真实** `node_modules`（提示 `Recreating /…/zcblog-v2/node_modules`，删掉 1037
个包）。已用 `pnpm install --frozen-lockfile` 恢复，随后回滚该修法。

**规则：临时 monorepo 不要软链根 `node_modules`；pnpm 会按 realpath 操作。**

## 3. 最终修法

只改 `scripts/release/verify-changeset-loop.mjs`：

1. 先检查三个包的关键产物（`tokens.css`、`packages/ui/dist/index.js`、
   `packages/og-image/dist/index.js`）；缺了就在真仓跑一次
   `node scripts/release/build-packages.mjs`。
2. 把包内容（含 `dist/`）拷进临时 monorepo。
3. 在**副本**的 `package.json` 里删掉 `prepack`——副本没有 `node_modules`，不应重跑构建；
   `dist` 已由真仓拷入。
4. `changeset add → status → version → pack → publish-plan` 照旧。

L6 验的是 changesets 链，不是包构建；包构建由 `build-packages.mjs`、包自身 test 和
release workflow 的 build 步骤覆盖。
