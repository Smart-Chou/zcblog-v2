共同条款：CC0 1.0 Universal（Public Domain Dedication）
--------------------------------------------------------
六个候选全部是 CC0 1.0。维基共享资源 API 对每个文件都返回：

    License              = cc0
    LicenseUrl           = http://creativecommons.org/publicdomain/zero/1.0/deed.en

    AttributionRequired  = false

CC0 正文第 2 条（Waiver）原文关键句（`CC0-1.0-legalcode.txt` 第 63–73 行）：

    Affirmer hereby overtly, fully, permanently, irrevocably and unconditionally
    waives, abandons, and surrenders all of Affirmer's Copyright and Related
    Rights ... including without limitation commercial, advertising or
    promotional purposes (the "Waiver").

结论：**覆盖本站商用与公开展示**（明写 including without limitation commercial
purposes），**不要求署名**（AttributionRequired=false），**无 ShareAlike /
NonCommercial / NoDerivatives 限制**，可自托管、可转码、可裁剪。

署名文案（法律上非必需，建议仍显示）
------------------------------------
CC0 不要求署名（AttributionRequired=false），但站点若要在 UI 上标明来源，
推荐统一为一行：

    Music: "<标题>" — <权利人> · CC0 1.0 (public domain)

例：
    Music: "Wikipedia guitar solo" — Leechfoot · CC0 1.0 (public domain)
    Music: "Sugerencia" — Salim Perchy / Gerardo Sarria · CC0 1.0 (public domain)

若采用上述署名，须同时可点到 https://creativecommons.org/publicdomain/zero/1.0/
（deed 页），这不是 CC0 的义务，只是惯例。


未采用的候选与原因（同批排查）
------------------------------
- Freesound（经 Openverse 索引，CC0）：如 "Typewriter.mp3" (pakasit21, 138049)、
  "heart beat.mp3" (greyseraphim, 21409)。文件页确认 CC0，预览 mp3 实测可取
  （heart beat: 200 / 892,760 B / audio/mpeg / 41.41 s / ~172 kbps）。
  **未采用原因**：Openverse 索引的是 cdn.freesound.org 的 *预览* 片段，Freesound
  对预览的再分发条款需逐个核对；且 Commons 那条路径已有 wikitext 许可模板可审计，
  取证强度更高。若 PO 想要更多音效，这条链路可用，但需补一层条款核对。
- "Comme Jospin - 09 - Joyeux Anniversaire.ogg"、"RADIO HUMMINGBIRD - 161 - true
  feelings.ogg"：CC0 但分类含 "License review needed (audio)" —— 即 Commons 社区
  尚未完成许可复核，取证强度不足，不用。
- Nightride FM 直播流：查无任何授权文本（站点 /terms /tos /about 全返回同一份首页，
  旧条款页 410 Gone）。**不可用**，与 D-0169 结论一致。
- Radio Paradise 直播流：运营方公开提供 stream URL 供第三方播放器消费，属「公开端点 +
  使用邀请」，非本文件所能替代的再分发许可；且它是**跨域**，须 PO 单独批准。
  详见 D-0169。
- 站内既有四条音乐条目（许嵩商业发行录音）：无任何授权文本，**不可自托管、不可热链**。
