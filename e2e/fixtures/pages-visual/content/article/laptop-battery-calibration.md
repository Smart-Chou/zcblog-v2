## 什么时候该校准

电量从 40% 直接跳到 8%，或者插着电也显示「正在充电」很久不掉——这才是电量计漂移的信号。

## 步骤

1. 正常使用到机器自动关机，不要中途插电
2. 静置 3 小时，让电芯电压稳定
3. 关机状态下连续充满，再多充 2 小时
4. 开机查看设计容量与实际容量

```bash
# macOS 上读原始读数
ioreg -rn AppleSmartBattery | grep -i capacity
```

## 边界

- 每季度一次足够，频繁深放反而加速损耗
- 长期插电使用的人，把充电上限压在 80% 更有意义
- 校准不会让老化电芯变新，它只是让读数说实话
